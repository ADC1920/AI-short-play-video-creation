## 0. 结论摘要

四个项目同属「agent 视频生产」方向但形态各异：OpenMontage=全流程制作平台（架构参考）、HyperFrames=代码渲染引擎（工具）、Hypit=爆款复刻工作流（理念）、Brag=单场景宣传片 skill（局部工艺）。**只吸收理念与局部工艺，不搬任何架构**——候选融合点 6 个，落点 3 个文件，技能内容零新增文件（本调研档除外）。

## 1. OpenMontage（calesthio/OpenMontage）

- 定位：agent 优先的端到端视频制作系统（12 条流水线 / 100+ 工具 / 700+ 指令文件）；无代码编排器，AI 编程助手即控制平面；创意决策与审查标准全部在 Markdown/YAML 中。
- 核心机制（实查摘录）：
  - 流水线：research → proposal → script → scene_plan → assets → edit → compose → publish，每阶段一个 stage-director skill + 可机检产物 + 审查标准
  - 前合成验证：交付承诺检查（标称「运动为主」却静图占比 80% → 拦截）、PPT 风险评分（6 维）、渲染器治理
  - 渲染后自审：ffprobe 验证 + 4 处抽帧（黑帧/破损覆盖）+ 音频电平（静音/削峰）+ 承诺核对 + 字幕检查——不过审不交付
  - 源文件探查：用户素材先探查（分辨率/编解码/音频通道/时长）再决策，不凭文件名猜内容
  - 参考视频驱动：粘贴参考视频 → 分析 transcript / 节奏 / 场景 / 关键帧 / 风格 → 2-3 个差异化概念 + 成本估算 + 样本
  - 预算治理：估算 → 锁定 → 结算三步；observe / warn / cap 模式；按行动审批阈值
- 与本技能对照：已有等价物——视觉验收纪律（对应其自审的「不假验收」精神）、先图后视频与重生预算（对应其预算治理的轻形态）、素材形态逐款核对（教训 L-10）、多会话档案（agent-log / continuity-log 承担 checkpoint 职责）。
- 可融合（理念级）：
  - [A] 对标参考流程（与 Hypit 合并，见 §3）
  - [C] 成片机检三查（ffprobe 对账 / 抽帧查黑帧 / 音频电平）→ 落 `references/transition-editing.md`
  - [E] 预算轻量账（估算 → 批量前确认 → 生成后记实际）→ 强化 `SKILL.md` 成本纪律既有条目
  - [C+] 交付承诺自查：「本片不能是静图轮播 / PPT 感」类承诺在分镜期与交付期各核一次——**实施时未采纳**（关联弱：本技能产物为生成视频，不存在 OpenMontage 式「标称运动、实际静图占比高」的典型风险；其精神已由视觉验收纪律覆盖）
- 不吸收：流水线 YAML、checkpoint 体系、7 维评分引擎、多提供商容错架构——系「全流程平台」骨架；本技能是单路线工艺技能，搬运即臃肿，其精神（阶段闸门 / 可恢复 / 决策留痕）本项目已有低成本等价物。

## 2. HyperFrames（heygen-com/hyperframes）

- 定位：HeyGen 官方开源；HTML/CSS/JS（GSAP / CSS / Lottie / Three.js 动画）→ 确定性 MP4（headless Chrome 逐帧 seek + FFmpeg 编码）；Apache 2.0；CLI（init / preview / render / lint / capture / beats / tts / transcribe）+ catalog 组件库 + variables 参数化批量。
- 与本技能对照：本技能主体=AI 生成（Seedance）；HyperFrames=代码渲染（文字动效 / 图表 / 数据可视化）——互补不冲突；本项目后期走剪映，代码渲染路线未启用。
- 可融合（工具指针）：
  - [F] 后期工具路线对照补一行（`transition-editing.md` 第十节）：代码渲染路线适合什么（文字动效 / 图表 / 片头包装 / 批量参数化变体 / 官网转视频）、不适合什么（实拍内容 / 复杂表演）、引入成本（Node.js 22+ 生态）
- 不吸收：CLI / Studio / catalog 全量集成——重依赖，按需再引入；其 `beats`（节拍检测）与 audio-voice 的 BGM 卡点思路可留指针。

## 3. Hypit（hypit-ai/hypit）

- 定位：用 AI agent 把爆款视频复刻为「可编辑可重跑的工作流」（画面 / 字幕 / B-roll / 特效），**词锚定**——元素跟随词而非秒；一条命令 100 个变体；代码渲染可选（存在零生成模型成本路径）。
- 可融合（理念级）：
  - [A] 对标复刻纪律（与 OpenMontage 参考驱动合并）：维度拆解（结构 / 节奏 / 钩子 / 字幕样式 / 素材穿插）→「保留 / 更换」两栏清单 → 差异化方案；红线=学结构不抄内容、不承诺逐帧复刻、不使用无权素材
  - [B] 词锚定迭代原则：改词 / 多语言迭代时保持词序骨架、只替换词内容，时间轴（台词折算 / 字幕 / 卡点）按既有规则重新流动，不手排秒表 → 落 `references/prompt-craft.md` 时间粒度节
- 不吸收：100 变体批量引擎与词对齐运行时（自有运行时，非文档可承载）；其「复刻范围可指定」（只借字幕样式 / 开场结构 / 素材穿插方式）已并入 A 的维度拆解。

## 4. Brag（latent-spaces/brag）

- 定位：Claude Code skill；读项目代码 → 计划产品故事（2 秒钩子 / 至少一处真实物料 / 每行字留足阅读时间 / 15-25s）→ 交 HyperFrames 渲染 → 校验 + 分享文案；「故事与渲染的所有权边界契约」清晰；海报帧=最佳帧（非任意帧）并烘焙为第 0 帧作缩略图。
- 可融合（局部工艺）：
  - [D] 发布包装：封面帧判据（画面完整 / 主体清晰 / 信息代表性）+ 烘为第 0 帧 + 分享文案要具体忌套话 → 落 `SKILL.md` 交付纪律附近
- 不吸收：插件分发机制与捆绑音乐资产——与知识技能定位无关。
