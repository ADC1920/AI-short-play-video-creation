## 一、项目概况

- **形态**：面料企业每期花型上新 → AI 时装走秀短片（多款模特依次出场的「流水线」走秀，加开场与片尾）。
- **工具链**：即梦 Seedance（先 2.5 探路、后定 2.0 Fast 为主）出片；剪映拼接包装；officecli 做交付文档渲染验收。
- **批次一**：20 款、16:9 横版首版 5 秒/镜，经 18 个提示词脚本版本迭代（三视图路线、流水线编排、素材绑定、动作时序、尾帧接力、操作单、衔接与运镜重构）。
- **批次二**：16 款 20 镜、9:16 竖版、5 秒/镜固定档、全片约 110 秒；素材形态变化（随手拍街图 + 已备三视图 + 多色款逐色）。
- **交付链**：docx 提示词脚本（粘贴即用）交付客户，客户按脚本在即梦生成，助手做视频验收与工艺维护——人机分工协作模式。

## 二、全流程（两批次沉淀的七步）

1. **素材盘点**：逐款核对模特图（街拍穿搭图）、面料保真基准（面料色卡或挂板图）、已备三视图情况；多色款逐色清点；未拍摄款剔除。
2. **三视图**：缺三视图的款/色用「街拍图作参考 → 白底多角度设定图（正/侧/背/脸特写四格）」补齐；验收三查（全身完整含鞋、花型对照色卡、各角度同一人同套衣）。
3. **提示词脚本**：每镜一条（操作单 + 素材绑定 + 镜头语言主句 + 顺序式时序 + 保真尾段 + 统一负面词）；生成机检（条数/机位分布/接力链逐环对齐/关键字覆盖）。
4. **生成**：客户按操作单在即梦生成（画幅、时长档、上传清单、提示词照单粘贴）；各镜相互独立可乱序并行。
5. **验收**：助手四查（花型保真／机位运镜到位／出场自然／返程状态）+ 抽帧分段核对（每段 4-5 帧：起手帧/中段/尾帧）。
6. **拼接**：剪映按脚本顺序直接拼接（切点踩 BPM 重拍）；字幕卡与开场标题后期叠加。
7. **归档**：成片入交付路径 `分镜视频/`；文档类交付新版生成后旧版自动归档 `_旧版归档/`（见第六节工具）。

## 三、核心工艺（实测有效）

- **参考图路线**：模特形象锁定用「白底多角度三视图」作参考图（比街拍原图稳定）；街拍图仅作三视图的生成源。三视图是素材图，多格并排采用横向布局，**不随成片画幅变化**。
- **雾端掩护 + 转播五机位轮换**：各镜独立生成、无逐帧接力——主体从尽端雾光渐显/中段行进出场、上一位背身走向深处渐远（位置误差被背身＋次要＋雾光掩护）；相邻镜机位与景别至少差两档（正面主机位/侧面机位/低机位/摇臂/定点轮换），切换由「换机位」语义自然掩护，位置微差不构成穿帮。成片直接顺序拼接，无需逐帧对齐。
- **顺序式时序**：目标平台对秒级时间戳响应偏晚（实测约 2 秒），动作时序改用「开场／随后／接着／最后」的顺序式指令，比时间戳更稳；每镜状态变化控制在 4 个以内。
- **时长分档与踩拍**：单镜时长按展示内容在平台档位（4-15 秒）内分档；音乐 BPM 与镜长匹配选点（如 120 BPM 下每拍 0.5 秒，任意整秒时长都是整拍）。
- **多色面料**：同款多色每色一镜（每次同框参考图 ≤2 更稳），不做多色同框长镜头。

## 四、实测教训（通用化，全量见技能对应章节）

1. **多素材模式不锁定首帧**（10.08 批次）：图生视频多素材模式下所有参考图均为软参考，模型不锁定第 0 帧构图——「上一镜尾帧＋显式起点」压不过模型构图先验，实测首帧人物位置偏差半程以上（瞬移）。修法：放弃逐帧接力，改雾端掩护＋多机位切换（让位置误差不可见），各镜独立并行。
2. **运镜指令必须是镜头语言主句**：运镜描述埋在长提示词的从句里会被模型无视（实测「缓慢推近」全体失效、全片固定机位）。修法：每镜只写一个主运镜、写成本镜镜头语言的主句。
3. **起点距离须匹配段内自然步速**（10.15 批次）：让模特「从 T 台尽端走到前端」，5 秒内按自然步速走不完——模型把出场过程压缩成「凭空闪现」（实测 0.1s 空台 → 1.3s 人物已到中景）。修法：起点改「中段行进中」（第 0 帧即含主体、无空台），时序显式写「行进过程全程连续可见、步伐与自然步速一致、不跳步、不闪现」。
4. **素材层与成片层参数分离**：三视图素材为横向多格布局，成片改竖版时素材无需重做（参考图提取人物身份，画幅由生成参数控制）。
5. **画幅变更的三件套**：成片改画幅＝生成参数 + 提示词构图句 + 场景底图三处同步（底图须重出对应画幅版本）。
6. **交付版本管理**：docx 成品多版本迭代时，新版交付后旧版必须自动归档（见第二节第 7 步与第六节工具）——旧版不散落交付根目录、不主动删除。

## 五、工作法（协作与验收）

- **样片先行**：批量前先出 2-3 镜样片（覆盖不同机位/时长形态），确认衔接与运镜后再批量。
- **抽帧验收**：视频验收用 ffmpeg 分段抽帧（起手帧/中段/尾帧）逐一目检——文件有效与命令成功不能替代视觉验收。
- **四查**：花型保真（对照面料色卡）／机位运镜到位（与本镜分配一致、末段停稳）／出场自然（无闪现跳变）／返程状态正确（背身走向深处）。
- **双层文档验收**：机检（程序核对条数/分布/接力链/关键字）+ 渲染视觉验收（逐页或抽验页面截图核版式）双过才算交付。
