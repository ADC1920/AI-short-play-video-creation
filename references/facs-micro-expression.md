# 面部表演工艺（FACS 微表情）

> 何时读：写实形态镜头要写人物表情时；特写/微表情/口是心非/情绪转折关键拍；某个角色表情反复崩、总出现莫名甜笑时。

## 一、为什么不用「开心 / 难过 / 邪魅」

结果词给模型的信息是零——「开心」可以是 100 种脸。AI 对「哪块肌肉、做什么可见动作、多大幅度、持续多久」的执行，远比对结果词稳定。FACS（面部动作编码系统，Ekman 学术框架）把表情拆成彼此独立的动作单元（AU），这就是给模型的「肌肉指令表」。

**核心原则：不写结果词，写肌肉动作 + 幅度 + 时序。**

## 二、五步法

1. **定潜台词**：这一拍角色真正想表达 / 想隐藏什么（说出口的话 vs 真实情绪——「口是心非」靠微表情制造）。
2. **选组合**：对照下面速查与配方挑动作（真笑/假笑、惊讶/恐惧这类易混组合先对照再写）。
3. **四区写全**：眉区 → 眼区 → 颧颊 → 嘴/下颌。缺区会让表情发空，或模型自由发挥崩脸。
4. **定强度与时序**：三档（痕/显/强）+「起—hold—落」。
5. **翻译成画面语言**：投喂正文只写肌肉的可见动作；AU 编号与档位记号只进给创作者看的说明（模型不识别编码——轻则浪费字数，重则被当画面文字渲染）。

## 三、四区速查（常用动作）

**上半脸**：眉心内侧上抬（悲伤/恳求）｜外眉抬、挑眉（疑问/玩味）｜眉下压（愤怒/专注；也是恐惧的加强件）｜上眼睑提、睁眼（惊讶/警觉）｜颊部抬起带动眼尾眯（**真笑之眼**）｜下眼睑收紧（目光变锐）。

**下半脸**：上唇上提（轻蔑/嫌）｜嘴角上提（笑的基本件）｜嘴角绷紧或单侧提（讥笑/克制）｜嘴角下垂（难过/委屈）｜嘴角向后横拉（隐忍）｜抿唇（克制/决心）｜嘴微张、下颌松（愣住/惊讶）。

**非 AU 的自主神经信号**（做「藏不住的真实」极好用）：耳尖泛红、喉结吞咽、出汗、呼吸变浅变急、瞳孔变化——身体出卖比脸诚实。

## 四、强度三档与时序

| 档 | 幅度 | 时长 | 用于 |
|---|---|---|---|
| **痕** | 10–25%（仅特写可读） | 起 0.2–0.3s、hold 0.3–0.8s | 藏情绪、日常、克制型角色、微表情 |
| **显** | 30–55%（中景可读） | 1–2s | 主要情绪、态度转折 |
| **强** | 60–80%（远景可感） | 爆发后 0.5–1.5s 回落 | 爆点、惊恐、大笑 |

- 任何表情都要「起—hold—落」，不全程绷在峰值；真笑可以让嘴角先动、延迟约 0.3s 笑意才到眼睛（更真实）。
- 峰值对齐台词重音字；句尾留 0.3–0.8s 余韵（这个气口正好承载余韵微表情），别让台词还没说完脸先松。
- 强度宁小勿大：默认从「痕」起，「强」只给爆点且不超过 80%（满格易成鬼脸）。R1 类克制表演全程不超「痕」。

## 五、三组最容易写错的

- **真笑 vs 假笑**：真笑 = 颊部抬起、眼尾眯（眼参与）+ 嘴角上提；只提嘴角、眼尾平直 = 社交假笑。要「皮笑肉不笑/职业微笑」就**刻意只给下半脸**——这是正写，不是缺项。
- **惊讶 vs 恐惧**：抬眉 + 睁眼 + 嘴微张是惊讶；再叠眉下压（前后眉肌同紧、目光定住）才是恐惧。少了这层只是「愣住」。
- **上唇上提 ≠ 嘴角下垂**：上唇上提 = 轻蔑/嫌；嘴角下垂 = 难过/委屈——写反情绪就反。

## 六、配套纪律

- **单侧要指定**：玩味笑、挑眉、单眼眨要写明哪一侧，并与视线/站位轴线一致。
- **不叠互相矛盾的动作**：同侧嘴角不能既上提又下压；眉不能既抬又压（除恐惧的前后眉肌同紧，那是特例）。
- **遮挡就写看得见的**：墨镜/侧脸/背对/阴影遮眼时，眼区拍不出来——改写眉与下半张脸、下颌、头部角度；只在眼睛真正露出时写眼区。
- **写实与动画分开**：本档主要服务写实形态；动画形态表情偏风格化，用造型/线条描述更贴（见 `frame-industrial.md`）。
- **与台词预算联动**：表情 hold 不得侵吞台词时间（语速折算见 SKILL.md 铁律区）——重写台词前先算。

## 七、常用情绪配方（起点组合，按角色性格调）

| 情绪 | 画面语言写法 |
|---|---|
| 压抑的悲伤 | 眉心内侧轻蹙、上眼睑微垂、嘴角努力放平（压住下撇）、视线下垂 |
| 玩味 / 揶揄 | 单侧外眉轻挑、嘴角单侧上提、眼尾保持平直不眯（假笑信号） |
| 隐忍怒气 | 眉下压、目光锐利定住对方、嘴唇抿紧后拉、下颌绷紧 |
| 真心欢喜 | 颊部抬起、眼尾眯、嘴角大幅上提、眼角带细纹 |
| 惊讶 | 内外眉齐抬、上眼睑提睁大、嘴微张下颌松 |
| 恐惧 | 眉抬起同时眉下压（同紧）、瞪眼、嘴唇向两侧后拉、身体后倾 |
| 嫌恶 | 上唇单侧上提、鼻梁轻皱、头微后仰 |
| 强装镇定 | 面部整体放松但喉结吞咽、呼吸变浅、手指微蜷（身体出卖） |
| 挑衅 | 嘴角单侧上提、下颌微抬、下眼睑收紧、视线从低处向上看 |
