# 素材资产与一致性工艺（路线 A / B 通用）

分镜再好，素材层崩了全白做。一致性问题的修复成本从低到高：**素材层 < 提示词层 < 后期层**——所有一致性问题先在素材层解决。

## 一、人物素材：锚点法

同一角色要出现在几十个镜头里，参考图必须「同一个人」。锚点法的核心：**先定一张锚点图，其余全部从锚点衍生**。

1. **出锚点**：正面全身（或正面半身）先出，按人物提示词逐轮修改直到满意——这张定身份（脸型/发型/体型/主服装）。
2. **衍生态**：大头照、侧面、背面、表情集、服装变体——每一步都**只参考锚点图**生成（把锚点图作为参考图/垫图喂给工具），不要直接另起文字描述生成。
3. **身份输入格式**：给视频模型做身份参考时，用「一张干净的脸部特写 + 一张单独的全身图」两张分开的图；**不要把正/侧/背拼成一图的三视图当身份输入**（会被读成多个人）。三视图仅在其过审用途（`face-workarounds.md`）或素材库展示时使用。
4. **被拦就走规避**：锚点或衍生态被人脸审核拦截时，按 `face-workarounds.md` 的五法处理（墨镜/网格/无五官/服装+头部组合/风格转绘）。
5. **命名一致**：衍生图的文件名就是 @ 引用名，与上传平台里的素材名逐字一致。

反面案例：同一角色每个镜头都按文字描述重新生成 → 脸型/发型逐镜漂移 → 全片像群演。

## 二、多视图组合：防 AI 偷懒

三视图/多视图素材，AI 经常把同一角度复制到两三个格子。提示词必须显式声明：

> 4 distinct different angles, no duplicate views, each panel shows clearly different orientation

或用中文逐格指定角度（左上正面平视、右上侧面 45°、左下纯背面……）。不写就等着收几张一样的。

## 三、ref 数量红线（多角色同框）

实测经验值（同框保真率）：

| 同框 ref 数 | 一致性预期 | 表现 |
|---|---|---|
| 1 个主角 | ~95% | 完美保 ref |
| 2 个主角 | ~80% | 可接受 |
| 3+ 主角 | <50% | 全员脸盲化 |
| 6+ | ~0% | 全部变通用形 |

SOP：同框镜头 **1 个主角 ref + 其余角色用文字描述或剪影**（silhouette）+ 背景虚化；需要保真的角色尽量单独给镜头。单镜 ref 数量控制在 2 以内。

## 四、ref 与文字的关系：引用即锁定

ref 引用和文字描述是**权重冲突**而不是叠加（图像 token 权重远高于文字描述，约 7:3）。@ 引用某素材后再用文字重描该主体外貌（脸型/服装颜色细节），模型会按文字重画、ref 降级为「风格参考」→ 角色变形。

- ✅ `@顾寒 @破败茶棚，拔剑突进，CU，急速甩镜，……`
- ❌ `@顾寒（黑色长发、灰色长袍、冷峻脸庞），拔剑突进，……`（重描 = 覆盖 ref）

外貌细节写在**素材制作阶段**（锚点提示词），不写在**镜头提示词里**。镜头提示词只写动作/景别/运镜/光线。

## 五、候选图选择制

- 每格/每素材先出 1–4 张候选 → 人工（或让用户）选优 → 定稿入库。镜头级的候选继承同一机制（每镜 1–4 张候选分镜图、选优作视频首帧），见 `references/frame-industrial.md`。
- **改 prompt 必先删旧图**：生成工具的「已存在跳过」逻辑会让旧图挡住新 prompt 的结果——改词重跑前先删掉旧文件。
- 构图/布局问题在图上改（图重生成本低），别指望靠视频提示词救。

## 六、文字入图规则

- 必要文字（招牌/工牌/屏幕 UI）保留，但必须显式声明清晰：`clear legible Chinese characters「具体字」, no garbled text`。
- 多余文字（测量数字、装饰性标注）从提示词删掉，纯增乱码风险。
- 弹幕/字幕类：只描述 **1 处**出现位置 + 滚动词（`ONE bullet chat scrolling`），写 N 次会画出 N 个。

## 七、素材编号建议（可选）

素材多时用前缀编号：C01 角色 / S01 场景 / P01 道具，@ 引用名 = 编号 + 名称（如 @C01顾寒）。多集项目跨集核对时不容易混。

## 八、人工把关清单（素材入库前）

- [ ] 风格统一（全片同一画风，没混进真人/3D）
- [ ] 脸、手不畸形（多指、崩脸直接重生）
- [ ] 角色三件套一致（脸型/发型/主服装）
- [ ] 多视图角度真的不同（没偷懒复制）
- [ ] 文字清晰无乱码
- [ ] 色调与全片视觉基准一致

发现问题 → 删该图 → 修提示词/锚点 → 重生。重生 1–3 张属正常；同一角色超 5 张说明锚点或风格词有系统性问题，回锚点层重修。

## 九、ref 库规模与成本节奏

- **规模标准（工业级）**：全套 ref 库目标 80–150 张——每角色 5–8 张（基础锚点 + 动作 + 表情）、每场景 3–5 张（多角度 + 多光线）、关键道具 30–50 张全角度。小体量单集可按下限裁剪，但角色基础锚点 + 正脸特写两张不能省。
- 素材阶段（角色+场景+道具）是全片**成本最低、杠杆最高**的环节——值得多花时间。
- 素材全部定稿、用户确认后再进分镜与视频阶段（镜头级关键帧工序见 `references/frame-industrial.md`）；视频阶段按集解锁、逐集确认（见 SKILL.md「成本与确认纪律」）。

## 十、非人形主角（题材相关）

拟人化主角（建筑/器物/概念形象）的素材有系统性偏置与专项对策（提前选材 / 否定子句 / 偏了重做的判据），见 `references/frame-industrial.md` 第四节。

## 十一、真人素材作首帧：重构图规范

用真人素材（模特图 / 实拍图）加工成视频首帧时（「换背景 / 换场景」类需求），核心认知：**换完背景的图就是视频首帧**——首帧锁死构图，主体位置、大小、朝向、接地全部由它决定，视频段的运镜只是在这个起跑线上运动。所以这一步不是「换背景」，而是「重构图」。

**开工前先核对原素材形态**：多数模特 / 街拍素材是 3:4 竖版、行进姿态接近全身，但长裙摆 / 长衣款常把裙摆拖到画面底边、**脚部被裁出画面**——只换背景会得到「悬空主体 + 无法走动的构图」（没有接地、没有前移空间）。逐张先看「脚是否入画」。

**首帧四要素（全片统一标准）**：

1. **轴线**：主体在画面水平中央（场景主轴线），不偏左不偏右——全片同一轴线
2. **大小**：全身入画，主体高度约占画面高度三分之二，位于画面中下部；头顶上方保留纵深空间（给迎面运动留位移空间）。人贴满画面时，缓推没有推进空间、后退跟拍无法保持全身
3. **接地**：双脚（鞋）入画、踩在地面 / 台面上，脚底与地面透视一致、有自然倒影接触感——脚不入画会得到悬空主体
4. **朝向**：面向镜头方向的行进 / 站立姿态（原素材的微侧身姿态可用，不要强行改成完全正面——改朝向容易连脸和服装一起改，损坏保真）

**重构图工序（图生图 / 扩图）**：

1. 脚部未入画：先向下扩图，补出双脚、鞋与脚下的地面
2. 换背景：整体替换为目标场景（保持主体与服装不变）
3. 扩画幅：向两侧扩展场景空间（补环境元素）
4. 位置校准：按四要素检查；主体过大时整体缩小留空间，过小时放大到标准

**重构图提示词模板（骨架，填入具体场景）**：

> 保持人物的五官、发型、服装图案、颜色与材质质感完全不变；把背景整体替换为【目标场景：光线 / 环境元素描述】；人物全身入画、位于画面水平中央，双脚踩在【地面 / 台面】上、脚下有自然倒影，人物高度约占画面高度三分之二、位于画面中下部，场景从人物身后向画面深处延伸；人物保持面向镜头方向的行进姿态；【画幅】构图；主体受中性白光，服装不染环境光、不偏色；画面中不出现文字与水印、不出现其他人

**首帧验收三查（每张重构图后过一遍）**：

1. 双脚入画且踩在台面上（不是悬空、不是被裁）
2. 主体特征与原始素材一致（换背景容易捎带改服装 / 图案，对照原图必查）
3. 大小与位置符合四要素（与上一张对比，人不忽大忽小、不忽左忽右）

**特殊角度的现实限制**：低机位 / 俯拍 / 侧面横移依赖拍摄角度与身位——原素材是平视中景时，图生图很难精确改俯仰角与身位；首帧按统一标准（平视）重构图即可，角度变化靠视频段提示词实现，生成不稳时降级为最简单的正面缓推。
