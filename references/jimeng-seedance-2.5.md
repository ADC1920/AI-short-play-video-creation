# 即梦 Seedance 2.5 规则与限制（CLI 实查档案）

> 实查时点 2026-10-10｜用途：使用 Seedance 2.5 出片前查规格、上限与审核口径；2.0 口径见 SKILL.md「平台硬约束」表
> 来源分层：①「CLI 实查」= dreamina-canvas CLI 对账号实查（权威，2026-10-10）；②「官方发布」= 字节 Seed 官方博客（2026-07-31 发布时点）；③「媒体实测」= 发布期记者实测与社区实测（有时效性，以生成时界面显示为准）

## 一、能力规格（CLI 实查）

| 项 | 规格 | 备注 |
| --- | --- | --- |
| 生成模式 | t2v（文生视频）/ m2v（图生视频·多素材）/ first_last_frame（首尾帧） | 网页版对应「文生 / 图生 / 首尾帧」入口 |
| 时长 | 4–30 秒，步进 1 秒 | 2.0 为 4–15 秒 |
| 画幅 | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 | 短剧竖版用 9:16，横版用 16:9 |
| 分辨率 | 480p / 720p / 1080p | 网页版发布期显示 720P；更高档按生成时界面 |
| 提示词上限 | 15000 字符 | 2.0 为 4000 字符；本技能「1300–1500 字符上限」为更早平台口径，2.5 不受此约束，但仍建议精确不堆砌 |
| 视频延长 | 支持多轮延长 | 官方发布；社区实测可再延两次至约 90 秒 |
| 片段编辑 | 支持按时间戳定向修改指定片段 | 官方发布；改局部不重抽全片 |
| 秒级时间戳 | 支持（`0s-3s：…` 写法），官方推荐 | 多镜一条 / 卡点场景的官方写法 |
| 白模参考 | 支持（3D 预演、运动参考、创意参考） | 复杂运镜可先出白模再正式渲染 |

## 二、参考素材规则（CLI 实查）

| 项 | 上限 | 文件限制 |
| --- | --- | --- |
| 图片 | ≤30 张 | ≤52.4MB/张；宽高 300–8192px |
| 视频 | ≤10 段 | 单段 1.8–30.2 秒；≤200MB/段 |
| 音频 | ≤10 个 | 总时长 ≤30 秒（官方发布） |
| 素材总量 | ≤50 个（图 + 视频 + 音频合计） | m2v 模式最少 1 个；首尾帧模式固定 1 或 2 张图 |
| 多视图主体参考 | 2.5 起支持 | 发布对比：2.0「不建议」→ 2.5「支持」；三视图须拆为单角度单图（一图一人），可作角色身份参考 |

引用方式：网页版用 @图片N 语法在提示词中绑定（如「参考 @图一…」）；CLI 用素材索引绑定。素材多时给每个素材写清「管什么」（身份 / 场景 / 运镜 / 节奏），不要只堆数量——绑定写法见 `prompt-craft.md` 第四节。

## 三、会员与积分（CLI 实查 + 媒体实测）

- **会员要求**：seedance_2.5 的 480p / 720p / 1080p 各分辨率档在 CLI 规格中均标记需会员（isVip）；实际能否保存运行以服务端准入与账号为准
- **积分消耗（媒体实测，2026-07-31 发布期，量级参考，以生成时界面为准）**：5 秒 720P 约 130 积分、10 秒 260、15 秒 390、30 秒 780（未开会员口径）；2.0 VIP 5 秒 720P 约 70 积分——2.5 约为 2.0 的 1.85 倍
- **量级估算**：百秒级成片（约 20 段 × 5 秒 720P）≈ 2600 积分/轮（未计重做）；1080p 与更高档以生成时报价为准；每镜按 2 次择优留用则预算翻倍——批量生成前先看积分余额与档位价格
- **省积分要点**：先 720p 试跑、定稿再出 1080p；先做首尾两镜样片跑通再批量；用片段编辑改局部代替重抽

## 四、提示词规则（官方发布 + 官方指南）

- **官方四段式结构**：镜头标题 / 时间戳 + 场景与主体（含动作细化）+ 镜头语言（景别 / 角度 / 运镜）+ 光影色调与音频；多镜一条用秒级时间戳分段（`0s-3s：…`）或「镜头 1/2/3」
- **动作写作四规则**（官方指南）：①肢体细化 + 程度量化（缓步走来、衣摆轻扬，不写「动了一下」）②优先低缓连续的小动作，回避狂奔 / 大跳 / 剧烈翻滚（崩坏重灾区）③写出动作衔接（惯性承接）④情绪具象外化（写身体细节，不写抽象情绪）
- **@ 引用即锁定**：@引用素材后不要再用文字重描该主体外貌（脸型 / 发型 / 服装颜色），ref 与文字是权重冲突；外貌在素材阶段定稿，提示词只写动作 / 景别 / 运镜 / 光线
- **生成参数不重复写进提示词**：画幅 / 时长 / 分辨率在生成界面设置即可，提示词空间留给创作指令
- **画面文字**：2.5 减少了字幕与背景音乐不受控的情况（官方发布）；若成片要求「画面不出现文字、字幕走后期」，仍要在提示词写负面约束，不依赖平台默认

## 五、已知限制与审核

- **真实人脸**：参考图含真实人脸会被审核拦截（Seedance 系列一贯行为）；规避法见本技能路线 C（墨镜遮挡 / 网格 / 无五官 / 服装+头部组合 / 风格转绘）
- **负向词**：不要写「不要出现 XX」式的过度负向清单（有触发审核与权重混乱风险）；核心负面约束收敛为短句写在提示词末尾
- **性能漂移**：平台行为随版本变化；本档案为 2026-10-10 时点口径，遇到与实际不符以实测为准并回改本档
- **保密与合规**：素材与成片涉商业内容时注意合规；不使用真实第三方人脸与品牌标识
