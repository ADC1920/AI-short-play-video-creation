# 分镜图工艺（三层分离与镜头级关键帧）

素材层之上、视频层之下还有一个独立层：**分镜图**——每个镜头的静态关键帧。本文件回答一个问题：素材图、分镜图、视频段三层工艺，哪些参数必须分离、哪些不能复用。

适用：任何「素材锁定角色 → 逐镜出片」的短剧/漫剧管线。文中所有数字为实测经验值（含小样本推断），随平台与模型版本漂移，不是物理常数。

## 一、三层工艺分离铁律（核心）

三层各自的身份与参数，**不可互相套用**：

| 维度 | 素材图（ref） | 分镜图（视频首帧） | 视频段 |
|---|---|---|---|
| 身份 | 角色身份证 | 视频首帧 | 动作连贯 |
| 光影 | 平光/中性（原型信息优先） | 戏剧光（主光+边缘光+体积光） | 沿首帧 + 动态光斑/粒子 |
| 构图 | 居中/多视图 | 三分律/三层景深 | 沿首帧 + 运镜 |
| 角色描述 | 完整外貌锁定（锚点词） | **只写动作，禁止重描外貌** | 同分镜图 + 运动动词 |
| 场景 | 纯色/简背景、少道具 | 三层景深（前景道具/中景角色/背景地标） | 沿首帧 |
| ref 引用 | ——（ref 就是它自己） | @主角 ref + 配角文字/剪影 | 引用定稿分镜图作首帧 |

**最大教训**：把素材工艺照搬到分镜图 → 全片分镜「平、淡、正面、无戏剧光」；更糟的是在分镜图里重描外貌（身体/脸/服装），模型按文字重画、ref 降级 → 角色形态偏离。两个污染方向都要防：

1. **风格词污染**：素材阶段附加的风格词（「中性/平面/均匀光」一类）若带入分镜图，会压掉要求的戏剧光——素材阶段自动附加风格词的逻辑，到分镜图阶段必须关闭。
2. **重描污染**：分镜图 CHARACTER 段只写身份锚定与位置（`(@角色_ref) — same identity, 位置`），外貌细节全部留在素材阶段；镜头提示词只写动作/景别/运镜/光线（与 SKILL.md「引用即锁定」同源）。

## 二、镜头级先图后视频（工序）

「先图后视频」不只用在素材层——**每一镜的构图都应在静态图上先确认**：

1. **出候选**：每镜先出 1–4 张候选分镜图（文生图或参考图编辑）。
2. **选优**：人工/用户选一张定稿，文件名即该镜首帧（约定 `<镜号>.png`，候选加后缀）。
3. **锁定**：定稿图作视频生成首帧（图生视频模式）。
4. **出视频**：在首帧基础上加动作与运镜。

费用结构（经验值）：静态图单价约为视频段单价的 1/15–1/20；构图问题永远在静态图上解决，别指望视频提示词救。改词重跑前先删旧候选图（防「已存在跳过」）。

候选数分配（经验）：关键镜头（情绪峰值/爆点/反转）4 张；标准镜头 1–2 张；过渡镜头 1 张。36 镜一集按此分配约 36–50 张，成本可控。

## 三、8 段 SOP 模板（分镜图专用写法）

清单式与时间轴式之外的第三种写法，专用于分镜图（第三种，配合三层分离使用）。段名保留英文作格式标记，内容用中文：

```
[CHARACTER] (@角色_ref) — same identity, 位置（三分线/前后景，不重描外貌）
[BACKGROUND] 背景层：剪影与虚化元素列表（1–3 个，soft bokeh）
[ACTION] 画面内运动：动作动词 + 部位/状态变化 + 道具状态
[SCENE] 场景三层：前景道具、中景元素、背景地标，浅景深
[CAMERA] 景别（ECU/CU/MCU/MS/LS/ELS）+ 角度 + 焦段等值 mm
[LIGHT] dramatic + 主光方向 + 边缘光 + 体积光 + 粒子
[TEXT] 字幕/画面文字规格（必要才写，写明位置与样式）
[STYLE] 风格标签串 + 负向声明（不出现文字水印等）
```

各段要点：

- **CHARACTER 只锚定身份**——`same identity` 短句 + 位置，禁止出现脸型/服装/体型等外貌词（外貌是素材阶段的事）。
- **ACTION 用画面内动词**——「拔剑出鞘、衣摆掀起」这类可见变化；抽象心理（「心生警惕」）换成可见末态（与 `prompt-craft.md` 末态法则一致）。
- **SCENE 三层景深**——分镜图与素材图最大的差异在场景密度：前景一件、中景一层、背景一个地标，画面才有纵深。
- **LIGHT 是分镜图的灵魂**——素材图平光换来的「干净」，到分镜图必须换成戏剧光（主光+边缘光+体积光），否则成片没有镜头感。
- **TEXT 能不走图就不走图**——只写必要文字（招牌/字幕样例），写明样式；重要文字后期加。
- **STYLE 收尾带负向**——风格标签（画风/质感/画幅）+ 一句负向（无文字、无水印、无多余人物）。
- **长度**：分镜图级提示词目标 1200–1400 字符，硬上限约 1500（与平台表一致）；超长拆段或精简，别硬塞。

完整示例（@顾寒，拔剑）：

```
[CHARACTER] (@顾寒_ref) — same identity, 画面左侧三分线, 半身入画。
[BACKGROUND] 背景浅虚化: 远山脊线剪影, 两根断柱, 浮尘光斑。
[ACTION] 右手拔剑出鞘半寸, 剑身反光扫过眉骨, 衣摆被穿堂风掀起。
[SCENE] 破败茶棚, 前景翻倒的茶碗与碎陶片, 中景长凳与冷灰火盆, 背景坍塌木梁与远山, 浅景深。
[CAMERA] MCU 近景, 低机位仰拍, 35mm 等值。
[LIGHT] dramatic 左上方暖色主光穿过棚顶破洞, 右后方冷色边缘光, 空气体积光, 浮尘粒子。
[TEXT] 无字幕。
[STYLE] 水墨厚涂国漫风, 粗线条, 低饱和青灰撞暖褐, 9:16 竖屏, cinematic, 画面不出现任何文字与水印。
```

## 四、非人形主角的拟物化偏置（题材相关）

拟人化主角（建筑/器物/概念形象的拟人）做素材时存在**系统性偏置**（特定题材实测经验，小样本）：写实地标易过度拟物化；传统古建题材高频出现「人头戴建筑」或 chibi 人体，直接影响后续所有镜头。

对策（按杠杆排序）：

1. **提前选材**：非人形主角优先简单几何/现代结构（玻璃塔/球体/几何体），避开复杂古建——素材不纯，后面救不回。
2. **显式否定子句**：每个主角**单独一行**写「[角色]的身体就是[本体]本身，不是穿着[本体]样式衣物的人、不是头顶[本体]装饰的人」——不能多个角色共用一句复数式（模型不认）。
3. **控制数量**：否定词 ≤5 个，堆多了反而混乱。
4. **判断标准**：否定子句边际作用有限（约三成改善量级经验值），**ref 本身偏了，加子句也救不回——重做 ref 是唯一解**。这与素材层「重生 1–3 张属正常、超 5 张回锚点层重修」的判据一致。

## 五、视频 4 模选择矩阵

出视频按该镜素材形态自动选档（做成批量脚本时可照此逻辑）：

| 模式 | 输入素材形态 | 占比 | 用途 |
|---|---|---|---|
| 图生视频（主） | 单张分镜图 | ~80% | 分镜图作首帧 + 动作提示词 |
| 首尾帧 | 该镜首帧 + 尾帧两张 | ~10% | 关键爆点，锁死段内过渡 |
| 多帧一镜 | 2–20 张关键帧 | ~5% | 复杂动作/一镜到底 |
| 全能参考（fallback） | 多图 + 视频 + 音频组合 | ~5% | 无分镜图时多素材兜底 |

自动判定顺序：有首尾帧用首尾帧 → 有单图用图生视频 → 有多帧用多帧 → 都没有则全能参考。关键镜头（爆点/转折）建议显式生首尾帧锁过渡。

## 六、长提示词与并发限流

实测规律：**长提示词与并发不可兼得**——长提示词（1400 字量级）单跑通过率接近全过；4 张以上并发时几乎全败（触发限流）。规则：

- 分镜图级长提示词：一律单跑，或并发压到 ≤4 并带重试与退避。
- 短提示词（<400 字）：可常规并发。
- 批量前先小批试跑探当前限流水位，再全量。

## 七、失败返回的快速分辨

三类失败的区分（与 SKILL.md 排障表呼应）：

- **改参数可解**：报错含参数/节点类字样（如 InvalidNode）→ 多半是提示词超字数，压到 1400 以内重提。
- **改词可解**：报错含生成失败/内容类字样 → 审核拦截，换词（反派词换氛围词、暧昧词换景别词，见排障表）。
- **改时机可解**：无明确报错或超时 → 网络限流，退避重试，别改词。

## 八、分镜图出图后的复查顺序

1. **身份**：还是不是 ref 那个人（崩了 → 先查重描与风格词污染）。
2. **构图**：景别/角度是否按意图（写明的运镜被忽略时，把它改成该镜的主要意图）。
3. **光影**：戏剧光是否到位（平了 → 查素材风格词是否带入）。
4. **文字**：有无乱码/多余字幕（只留必要文字）。
5. 全部通过才进视频；不过就删图修词重出，别带病进视频段。
